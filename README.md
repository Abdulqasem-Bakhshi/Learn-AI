## Learn-AI

In this repo you will find all of my learning projects for AI implementations. Each learning project is separated by a folder.

## Preliminary Explanation

Hugging Face = where the model files live
Transformers = Python software that knows how to run the model
PyTorch = the engine doing the neural-network computation

## Preliminary Actions

1. Open VScode + New Project + Terminal

2. Run the following commands (line by line):
   python -m venv .venv
   .venv\Scripts\activate

3. Once your Virtual Environment is made, do the following:
   pip install "transformers[torch]"

4. Run python script. E.g., models\qwen3(0.6B)\app.py
